## What the code shows (it differs from the audit in places)
- **G3 is confirmed.** In `server/services/stripeService.js:181`, a successful checkout sends users to `/dashboard?onboarding=success`, which only shows a toast. First-report defaults are real: the leak engine and scorecards read the saved venue profile when a report runs, so an unprofiled location gets generic defaults.
- **G1 is confirmed, and the dead end is worse than described.** The checkout cancel link is `/register?cancelled=true`. `/register` is only for signed-out visitors, so a signed-in user is silently sent back to the dashboard. There's no banner for `pending` users there. The Billing page shows their plan as "Current Plan" with no button to check out, and says "$249 Paid" even though they haven't paid.

- **Not in the audit:**
