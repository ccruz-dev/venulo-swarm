# Dashboard data contract

The JARVIS dashboard reads **one file**: `status/dashboard.json` in this repo
(raw URL: `https://raw.githubusercontent.com/<owner>/venulo-swarm/main/status/dashboard.json`).
It is regenerated by `scripts/runner.sh` on every poll and enriched by Soup's
reviewer job. No auth needed — the repo is public.

## `status/dashboard.json`

```jsonc
{
  "updated": "2026-09-29T22:48:24Z",          // ISO-8601 UTC, regenerated each poll
  "agents": {
    "runner":     { "state": "online" },
    "claude-code":{ "state": "working | standby",
                    "current_brief": "2026-09-29-slug | null",
                    "current_title": "Brief title | null" },
    "codex":      { "state": "working | standby",
                    "current_brief": "… | null",
                    "current_title": "… | null" },
    "soup":       { "state": "standby",
                    "note": "reviewer job enriches this",
                    "last_review": "2026-09-29T18:00:00Z | null" }
  },
  "briefs": [
    { "id": "2026-09-29-slug", "title": "…", "owner": "claude-code | codex | soup",
      "status": "open | claimed | done | needs-human",
      "budget": "cheap | standard", "priority": "low | normal | high" }
  ],
  "tokens_today": {
    "claude-code": { "input": 12345, "output": 678, "runs": 2, "unknown": 0 },
    "codex":       { "input": 0, "output": 0, "runs": 1, "unknown": 1 }
  },
  "stats": {
    "done_total": 7, "open": 2, "claimed": 1, "needs_human": 0,
    "xp": 700                                   // done_total * 100
  }
}
```

Notes:
- `tokens_today` resets by UTC date. `unknown` counts runs where the agent did
  not report usage (e.g. Codex). Token counts are measured, never estimated.
- `xp` is mechanical: 100 XP per completed brief. Levels/streaks are computed
  by the dashboard, not stored here.
- `status/tokens.jsonl` holds the full per-run ledger (one JSON object per
  line: `ts, brief, owner, exit, input_tokens, output_tokens, model`).
- `status/runner.json` is the raw runner heartbeat; `dashboard.json` is the
  aggregated view. Prefer `dashboard.json`.
